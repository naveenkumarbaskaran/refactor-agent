# refactor-agent

> AI code refactoring — detects smells, applies fixes, explains every change.

## What it does

Scans for long methods, god classes, duplicated logic, and deeply nested conditionals. Proposes concrete refactors with before/after diffs. Applies changes with your approval.

## Quickstart

```bash
pip install refactor-agent
```

## Usage

```bash
refactor-agent scan src/ --smell long-method --auto-fix
```
